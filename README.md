Audio Assist

Audio input (microphone or file) → Whisper ASR → Piper TTS → audio output (WAV)
Backend is built with FastAPI.
Frontend is plain HTML / CSS / JavaScript using browser microphone recording type shii

MUST 
  Install requirEments.txt
  Install ffmpeg (System wide for some reason (not sure why))
  Install Piper TTS:
      Backend/models/piper/en_US-lessac-medium.onnx
      Backend/models/piper/en_US-lessac-medium.onnx.json)
